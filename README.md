# My Claude Skills

A collection of custom skills for Claude / Claude Code.

## Quick Download (Single Skill)

Replace `product-landing` with the name of the folder you want to download. The folder will be downloaded directly into your current directory.

### macOS / Linux

```bash
curl -sL https://github.com | tar -xz --strip-components=1 "*/product-landing"
```

### Windows (PowerShell / CMD)

```powershell
curl.exe -sL https://github.com | tar.exe -xz --strip-components=1 "*/product-landing"
```
